Risks

Decisions are made for each specific project

Participation in a commercial project involves risks, including changes in timing, costs, procurement terms and counterparties' actions. Known material risks are not hidden from a public project card; if a safe description is not possible, the project is not published.

The website does not accept money, enter into investment agreements or promise returns or repayment.
